# Cat Journal Starter

A React Native journaling app built with Expo. This is the starter project for the **Intro to React Native** live session.

## Getting Started

1. Clone this repo

git clone https://github.com/clydebankmedia/intro-to-react-native-example.git
cd intro-to-react-native-example

2. Install dependencies

npm install

3. Start the app

npx expo start

4. Scan the QR code with **Expo Go** on your phone

## What's Included

- Tab navigation with Expo Router
- Journal screen with pre-built styles
- About screen
- All imports ready to go

## What We'll Build Together

During the live session, we'll add:

- A scrollable list of journal entries using FlatList
- A floating action button to create new entries
- A modal with text inputs for writing entries
- State management to save and display entries
